# 孩子档案 + 错题本 · 设计方案

> 版本目标 v1.3.0。纯前端、localStorage、无后端。

## 一、数据模型

### 1. 孩子档案 `cnmChildren.v1`（沿用上游结构，本地重建）
```js
{
  current: 'c1abc',              // 当前选中的孩子 id
  children: [{
    id: 'c1abc',
    name: '小明',
    grade: 7,                    // 备注用，不筛内容
    textbook: '人教版',           // 备注用
    createdAt: '2026-10-24T...'
  }]
}
```
- 最多 8 个，昵称不可重名
- 删孩子时一并删掉他的错题本

### 2. 错题本 `cnmMistakes.v1`（新增）
```js
{
  c1abc: {                       // 按孩子 id 分组
    math: {                      // 按学科分组（math/english/physics/chinese）
      cnm_221: {
        id: 'cnm_221',
        status: 'weak',          // weak | shaky
        wrongAt: '2026-10-24T...',   // 最近一次答错
        correctStreak: 1,        // 连续答对次数（0/1/2）
        testCount: 3,            // 被抽测次数
        lastTestedAt: '...',
        priority: 2.4            // 抽题权重，见下
      }
    }
  }
}
```

### 3. 抽题记录（用于「下次必现」）
状态直接从 `correctStreak` 推导，不需要额外表：
- `correctStreak === 1` → 该知识点**下次抽到必须是它**（100% 出现）
- `correctStreak >= 2` → 移出错题本

## 二、错题本收录规则

| 引擎结论 | 是否收录 | 初始 status |
|---|---|---|
| `weak`（同点两次都错） | ✅ | `weak` |
| `shaky`（一错一对） | ✅ | `shaky` |
| `mastered`（一次就对） | ❌ | — |

> 注意：错题本收录的是**知识点**，不是单道题。

## 三、抽题权重（核心算法）

每次从错题本抽 N 个知识点，权重：

```
基础权重：weak = 3.0，shaky = 1.5
加成：每答错一次 ×1.6（记录在 priority 里累乘）
必现：correctStreak === 1 → 权重设为 Infinity（无条件入选）
```

实际实现用**分层抽样**而不是纯权重随机，保证「必现」和「错得多更常出」：

1. 先取所有 `correctStreak === 1` 的点 → 必选（若有超出 N，随机取 N 个）
2. 剩余名额按权重做无放回加权抽样
3. 错题本总数 < N → 全部用上

## 四、连续答对与移出

答题时（点目标是错题本来源）：
- 答对 → `correctStreak += 1`
  - 达到 2 → 移出错题本
- 答错 → `correctStreak = 0`，`priority *= 1.6`（封顶 12），`status` 更新为 weak

## 五、页面与导航

导航：首页 / 知识图谱 / 诊断 / **档案** / **错题本** / 关于

### `children/index.html` 档案页
- 卡片列表：头像（首字母）、昵称、年级、错题数（分学科）
- 新建 / 编辑 / 删除 / 设为当前
- 当前孩子高亮

### `mistakes/index.html` 错题本页
- 顶部：孩子切换 + 学科页签（数学/英语/物理/语文）
- 统计条：错题总数、薄弱数、不稳数、待确认数（correctStreak=1）
- 列表：按权重降序，显示知识点名、册章、状态标签、答错次数、连续答对数
- 操作：
  - 「开始复习」→ 弹题量选择（4/8/12/16/20，默认 8）→ 跳到诊断页
  - 单条：查看图谱、手动移出
- 空状态：引导去诊断

### 诊断页改动
- 开始页顶部加「当前孩子」选择器（必选，无档案时引导去建）
- 未选孩子 → 「开始诊断」按钮禁用 + 提示
- 答题时把 `weak`/`shaky` 写入错题本
- 结果页显示「本次新增 X 个错题，移出 Y 个」

## 六、错题本复习会话

跳转 URL：`diagnose/?subject=math&mistakes=1&limit=8&seed=xxx`
- 诊断页识别 `mistakes=1`：从错题本按权重抽 N 个点，作为 targets
- 标签显示「错题复习：N 个知识点」
- 结束时不回溯先修（避免复习扩散到整章），只测这 N 个点
- 每个点最多 2 题（沿用引擎规则）
- 结果页额外显示：本次移出 X 个、还剩 Y 个

## 七、实现顺序

1. `assets/children.js` — 档案 + 错题本 lib（含抽题算法）
2. `children/index.html` + `page.js` + 样式
3. `mistakes/index.html` + `page.js` + 样式
4. 诊断页接入（孩子选择、错题写入、复习模式）
5. 导航加两项（三页）
6. 验证、截图、打包 v1.3.0

## 八、边界情况

| 情况 | 处理 |
|---|---|
| 无孩子档案 | 诊断页禁用开始，提示先建档案 |
| 当前孩子被删 | 自动切到第一个 |
| 错题本为空 | 「开始复习」禁用，提示先做诊断 |
| 抽题数 > 错题数 | 全部用上 |
| 知识点在某学科错题本，但为另一学科做题 | 分别存储，互不干扰 |
| 清除浏览器数据 | 全部丢失（页面上明确提示） |
| demo 模式 | 不写档案、不写错题本 |
| 同一知识点换了题目再答错 | `priority` 继续累乘 |
